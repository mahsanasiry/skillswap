# SkillSwap

A peer-to-peer skill exchange platform. Teach what you know, learn what you want.

> Work in progress. See the project plan for the build steps.

## Getting started

```bash
npm install
npm run dev        # http://localhost:3000
npm run lint
npm run typecheck
npm test
npm run build      # static site in ./out
```

## Deploying to GitHub Pages

The build uses `GITHUB_PAGES=true` to add the `/skillswap` base path (set up in the final step).
